VIXCLO — Easy Edit Guide

Delivery Charge

Open config.js and change:

deliveryInsideCTG: 60,
deliveryOutsideCTG: 130

There is NO free delivery.

WhatsApp

whatsappNumber: "8801XXXXXXXXX"

Use the international number without + or spaces.

Products & Prices

Open products.js. Change product name, price and image path.

Designs

Replace files inside assets/designs/. Keeping the same filenames is easiest.

Logo

Replace assets/vixclo-logo.png with your own logo using the same filename.

Mockups

Replace files inside assets/mockups/.

Home Page

index.html controls content. style.css controls colors, spacing and layout.

Custom Lab

custom.html is the customization page: front/back design, drag, resize, color, size and order flow.

Online

For a free demo, upload the project to GitHub and enable GitHub Pages. A real live admin dashboard that changes the public website for everyone needs a backend/database.
